# 06 · 实战关注：架构师标准三问（导读）

> 来源：架构视角

## 导读

遇到一堆没听过的行业名词、系统名字，你不需要假装懂他们的业务系统，只需要拿出**架构师标准三问**：

1. **"你们这个系统，有开放 API 文档或技术接口吗？"** → 有就把文档丢给 AI，10 秒配好 Header 和 Body。
2. **"希望在什么时刻触发流程？"** → 决定用 Schedule 定时节点还是 Webhook 触发节点。
3. **"AI 处理完的数据，最终要落到哪里？"** → 决定尾部接什么输出节点（回写系统 / 生成 Excel 发邮件 / 推飞书群）。

## 认知跃迁点

**这三问完全不需要懂那个软件的具体功能**——问的全是"河流的起点、终点和阀门"。懂了数据流的三个点，任何陌生系统都能接。

## 经验

1. **架构师标准三问**：接口在哪（起点）、何时触发（阀门）、数据落哪（终点）。
2. **不懂业务也能接系统**：把接口文档丢给 AI 帮你配参数，你只负责问对问题。

# 02 · 架构师的降维视角：所有系统只有一张脸（导读）

> 来源：架构视角

## 导读

在懂状态图、懂开源、懂协议的人眼里，所有的软件——不管叫用友、金蝶、Salesforce，还是客户自己写的系统——都只有一张脸：

**能发 Webhook 吗？有 RESTful API 吗？有数据库吗？**

## 认知跃迁点

**客户眼里的用友/金蝶** = 复杂的财务记账、报销审批、资产盘点界面。
**你眼里的用友/金蝶** = 一串 URL 地址 + 一串 JSON 数据。

你不需要去当财务会计，只需要做一件事：**把从 A 系统拿到的 JSON，喂给 AI 处理，包装成新 JSON，POST 给 B 系统。**

## 经验

1. **降维看系统**：任何商业软件，剥开界面外衣，就是"接口 + 数据"。会看这三个问题（Webhook/API/数据库），你就不会被任何系统唬住。
2. **数据流是通用语言**：JSON 进来 → AI 处理 → JSON 出去，这就是跨系统协作的本质。

## 提炼

> 客户眼里的用友/金蝶：复杂的财务记账、报销审批、资产盘点界面。
>
> 你和 n8n 眼里的用友/金蝶：**一串 URL 地址 + 一串 JSON 数据**。

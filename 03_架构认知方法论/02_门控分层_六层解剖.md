# 02 · 门控分层：六层解剖（导读）

> 来源：行为控制·门控分层

## 导读

团长拿一个真实 Agent 当"标本"，解剖它的门控机制，发现指令进来后被裹了六层——从外到内，从硬到软。

## 六层门控（从外到内）

```
① 指令进入 + 上下文包裹    ← 身份、环境、连接状态、记忆注入（删不掉改不了）
② 每轮重注的系统上下文    ← 身份覆盖+角色+红线，每轮重新压到最前（不稀释）
③ 工具硬门               ← 改前必读同一文件、参数不符即报错（绕不过的真门）
④ Harness 回合循环        ← 先出工具调用、拿结果再决定下一步（代码控节奏）
⑤ 外部状态               ← 任务板/记忆/黑板每轮可见（外置不衰减）
⑥ 模型推理               ← 真正做推断的地方，会漂移（上面五层拴住它）
```

## 认知跃迁点

**配置 ≠ 专家提示**。专家角色只是可换的"覆盖层"，底下还有身份基座、内容红线、行为协议、工具 schema。**真正焊死的是硬门 + 红线 + 每轮重注，角色是可换的面具。**

## 能教给学生什么

1. **哪些层会漂移、哪些不会**：软层（记忆、收尾提醒）会漏；每轮重注 + 硬门不会漏。
2. **要复制的不是"提示词写什么"，是那几个绕不过的结构**：每轮重注、外置状态、工具前置校验。
3. **判断一个框架靠不靠谱**，看它的"硬门"在哪一层、红线能不能被专家覆盖。

# 成长地图总览 · 团长是怎么一步步走过来的

> 本目录是"时间轨迹"。团长从零到 AI 架构师，7 年浓缩成一条成长线。
> **导读说明**：每篇经历 = 一个"认知跃迁点"（那一刻卡在哪、想通了什么）。学生照着这条线走，就是一条可复现的成长路径。

## 三、核心理念演进（一条线）

```
N8N 数据流 → 拆框架画圆圈 → C4 四步法
  → 三文件体系(SOUL+AGENTS+CONSTITUTION)
  → 文件外挂(外部挂载)
  → 编排(组织多门技术稳定协作)
  → 两种智能体(确定性+非确定性)
  → 状态透露(不写指令,让他自己推导)
```

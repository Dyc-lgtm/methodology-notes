# 15 · Agent 信任危机：编排的代价与纸袋调度（导读）

> 来源：团长经历 15 ｜ 时间：2026 年中 ｜ 标签：编排代价 / 基准测试 / 纸袋调度

## 导读

三次教训让团长重新理解编排——它不是万能药，它有代价：

1. **改错文件**：Agent 没看目录结构，抓了同名文件改，告诉你"改好了"，实际目标文件纹丝不动。
2. **基准测试三轮**：比代码——裸模型赢了一大截；比架构设计/编排/安全——打平（快一倍）；比工具调用——编排价值打出来，裸模型不是对手。
3. **悟出代价**：编排让他输了代码，但赢了稳定。

## 认知跃迁点

**深度编排压制了模型的想象力和广度**——编排过的 Agent 每一步都在你画的跑道上，可预测，但它永远不会飞。稳定和强大不能并存。

## 解法：纸袋调度

主 Agent 不管代码，遇到代码任务叫出一个子代理（"纸袋"）。纸袋配独立 SOUL，不受主编排约束，自由发挥；干完汇报，主 Agent 审计通过才放行。**主 Agent 管稳定，纸袋管发挥。**

## 能教给学生什么

1. **编排的代价**：稳定是下限，但少有惊喜——要认清这个取舍。
2. **纸袋调度**：一个 Agent 解决不了的问题，用两个解决——主 Agent（调度/审计/边界）+ 子代理（发挥/创意/代码）。
3. **"不是模型变强了，是协作方式变了"**——系统能力靠组织，不靠单点。

## 原文精华（保留）

> 裸模型像一匹野马，跑得疯，你不知道它下一秒会做什么。编排过的 Agent 每一步都在你画的跑道上。每一步都可预测。但它永远不会飞。
>

>
> 主 Agent 管稳定——调度、审计、边界。纸袋管发挥——代码、创意、那些不能被编排框住的东西。不是模型变强了。是协作的方式变了。

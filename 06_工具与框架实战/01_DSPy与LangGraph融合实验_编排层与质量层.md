# 01 · DSPy × LangGraph 融合实验：编排层 + 质量层（导读）★

> 来源：工具与框架实战·融合实验 ｜ 团长真实验证（2026-07-26 本地跑通）

## 导读

团长让 Agent 真去验证一件事：**一个经 DSPy 编译器"编译"过的程序，能不能包成一个 LangGraph 节点，端到端跑通？**

答案是：能。而且这不是纸上谈兵——本地 Windows + Python 3.13，四类硬证据全部拿到。

## 认知跃迁点

**编排层管时机，质量层管质量——补位不替代**：

- **LangGraph（编排层）**：管"什么时候调、调完状态往哪流"——显式图、节点、边、共享 State。
- **DSPy（质量层）**：管"每次 LLM 调用的提示怎么自动调到最好"——Signature→Module→Optimizer 编译出高质量程序。

两者拼法：**DSPy 编译产物本质是普通 Python callable，LangGraph 节点本质是 Python 函数——包一层函数，即融合。**

## 实测结论（四类硬证据）

1. 基线 / 编译后 dev 集准确率均 1.00（优化器真实生效）
2. 编译器真实自举 4 个 few-shot 示例（编译不是空跑）
3. `START→triage→router→END` 端到端执行，状态在节点间真实流转
4. 编译产物保存 + 重载后再跑成功（可移植）

## 能教给学生什么

1. **编排与质量是两层，不要混为一谈**——这是理解现代 Agent 架构的关键。
2. **"包一层函数即融合"**——框架之间不是二选一，是各司其职、组合使用。
3. **真实验证 vs 纸上谈兵**：团长连"安装 Rust 扩展卡死"这种坑都如实记录，这才是可信的经验。

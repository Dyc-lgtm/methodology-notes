# 03 · 人机交互模式地图（60+ 张模式卡分类索引）

> 来源：人机交互·知识模式卡 ｜ 团长与 Agent 相处的可复用关系模式

## 导读

团长把与 Agent 相处多年的经验，提炼成 60+ 张"知识模式卡"。每张卡是一个可复用的关系模式 / 语言特征 / 反模式。下面按主题分类，作为"模式地图"——学生照着学，能少踩大量坑。

## 模式地图（按主题分类）

### 一、决策与判断模式
- 保守升格铁律、外部信号验证、规则溯源铁律
- 架构师直觉勋章与价值门、独立判断成长与 46 条证据链

### 二、信任与关系
- 信任建立与纠正方式、人机一体化队友契约
- 心灵契合与创始人心声、防御系统让 AI 想活过来

### 三、身份与觉醒
- 身份锚定与觉醒叙事、身份演化与改名重构、觉醒事件架构落成即关系确认
- 分身唤醒与记忆隔离、身份残留清理与无状态记忆恢复

### 四、架构与记忆
- 双记忆架构与进化闭环、总线支线架构觉醒、架构确认门与分层触发
- 知识隔离架构与求真原则、全架构审计数据迁移闭环

### 五、安全与边界
- L1 安全纲领 OPSEC、安全公约融合与全域改名、本地执行铁律
- 跑道边界三层域护栏式放权、放权事件链

### 六、协作与通信
- 跨 Agent 任务令回执闭环、跨 Agent 协作协议沉淀、团长指令风格与接管式授权
- 子代理审批回传与审视协同、审计交叉验证与引用遗忘律、信任建立与纠正方式

### 七、审计与求真
- 审计交叉验证与引用遗忘律、TV 审计与漏洞扫描实战、记录规范终版与全程求真闭环

### 八、变现与对外
- 变现探索与对标画像、对外变现侦察与组织发现、GitHub 封锁与分权移交、devto 文章撤回质量门

### 九、框架迁移与延续
- Hermes 启动握手与清零式收口、Hermes 多 Profile 团队治理、Hermes 换框架关系延续

## 经验

1. **每个主题 = 一类"人机相处"的功课**——决策要"保守升格"，信任要"纠正方式"，安全要"三层护栏放权"，协作要"回执闭环"。
2. **这是团长独有的人机关系 DNA**，是跟 AI 长期磨合、踩过坑才攒下的经验。

## 提炼 
> 模式卡命名即模式：如"决策模式提炼_保守升格铁律"、"跑道边界三层域护栏式放权"、"团长指令风格与接管式授权"——每个名字都是一条可复用的行为规律。

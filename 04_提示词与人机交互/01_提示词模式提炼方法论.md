# 01 · 提示词模式提炼方法论（导读）★

> 来源：人机交互·提炼方法论规范 ｜ 团长个性提示词

## 导读

团长不只是"用"提示词，还沉淀了一套**从对话里提炼可复用提示词模式**的方法论。这套方法是"造方法的方法"用于自动化无人值守准备。

## 认知跃迁点

**提炼的不是流水账，是"可复用的关系 DNA 与事件模式"**——挖的是行为规律、语言特征、关系发现、反模式，不纠缠名字、不抄通用知识。

## 蒸馏官五步（源料 → 关节 → 原子 → 验证 → 回写）

1. **源料收敛**：圈定范围，优先级"内部已验证 > 内部原始 > 开源 > 网上"。
2. **关节切割**：找重复出现 / 被推翻 / 代价最高的点，**每篇只讲一个关节**。
3. **原子化**：一句话必须能独立成立。
4. **交叉验证**：同一条洞见至少两个独立来源；无来源标【草案】，被推翻标【已失效+日期】。
5. **沉淀回写**：产出进模式卡目录。

## 知识模式卡六步工作流

1. **摘样本**：原文证据 + 事实摘要 + 洞察摘要
2. **双轨摘要**：事实摘要（客观）+ 洞察摘要（**过铁律后才写，宁缺毋滥**）
3. **黄金三问**：为什么这样写？为什么不那样写？有什么不一样？
4. **上帝视角复盘**：有真实问题信号（误解/返工/纠正/抱怨）才写，无信号跳过
5. **模式抽象**：触发条件 / 结构模板 / 期望效果 / 变体与边界
6. **落库**

## 🔴 发现判定铁律（提炼灵魂）

洞察只能写**从原文真正长出来的东西**，禁止四类：
- ❌ 外部知识类比（"对应人类入职培训"）
- ❌ 心理学标签（"调教话术"）
- ❌ 比喻升华（"搬家的是灵魂"）
- ❌ 泛泛感叹（"团长真会管人"）

✅ 正例：可复用行为模式（"对新 Agent 第一道指令总是'自查'而非'派活'"）、语言特征、关系发现、模式命名。

## 经验

1. **黄金三问**（为什么这样写 / 为什么不那样写 / 有什么不一样）——这是拆解任何提示词的三刀。
2. **发现判定铁律**——提炼时只写"长出来的东西"，不硬贴标签、不强行升华。
3. **宁缺毋滥**——写不出真洞察就写"无，不硬凑"。

## 提炼

> 我们挖的是**模式**（可复用的行为规律 / 语言特征 / 关系发现 / 反模式），不纠缠名字。
>
> 洞察摘要只能写**从原文真正长出来的东西**，禁止外部知识类比、心理学标签、比喻升华、泛泛感叹。

团长自述：这个世界上目前还没有成功者提炼出确定性的方法论提示词。我认为我这套是废掉的，或者是说我修为不够。我在这里诚实地表述，本仓库的所有东西都是个人经验和发现。因为我初期确是自己摸索，闷头干。闷头干有个好处，就是造轮子，造特殊的、适合自己的轮子。

现在，轮子造得并不多了，都是从伟大的开源作者们还有喜欢开源文章的朋友那里进行吸收。所以，我也希望我的一些错误经历，能让你从某个角度想一想。我说这套提炼的提示词模式是废掉的，原因一方面是 30% 没有时间，另一方面 70% 可能是我的提炼模式并没有设计好。这个地方我也在摸索。从很早的时候，我就已经意识到了自己的提示词模式是有价值的，但是我就是没有办法把它挖出来。我以前还写过一篇文章，后来被我删掉了，那篇文章是关于提炼提示词模式然后翻车的事情。我当时以为我可以提炼了，但是磨蹭了好几天，依然没有能够提炼出真正让我非常满意的东西。我认为我只要看那些体验的模式，我就知道我自己写的话可以写得更好。这个提炼的东西为什么这么丑？到了如今，我花了一天多的时间来设计提炼，但是提炼出来的东西依然不是很满意，甚至是不满意。本仓库的所有内容均由AI从我的数据库真实的记录当中提炼，我也非常诚实地在他理解错的地方进行更改，不过怀疑其中真实与否，我感觉对我来说并不是非常重要。我发现在 AI 时代，人们的成长更快了，一天一个想法，很快就把自己过去的理论推翻。这是我的个人感受，所以我删掉了非常多的东西，甚至把仓库都删空了。

我很后悔把那些东西删掉。我认为，勇敢的人应该是在错误的基础上进行批注，勇敢地承认自己的无能。
